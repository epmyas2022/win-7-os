# CMD Reference

---

## Commands

| Command    | Description                         |
|------------|-------------------------------------|
| `help`     | List all available commands         |
| `cls`      | Clear the screen                    |
| `echo`     | Print text to the terminal          |
| `date`     | Show the current date               |
| `time`     | Show the current time               |
| `dir`      | List files in the current directory |
| `cd`       | Change directory                    |
| `color`    | Change terminal colors              |
| `start`    | Launch an application               |
| `animate`  | Play an ASCII animation             |
| `prompt`   | Show the current path               |
| `type`     | Read a file                         |
| `whoami`   | Show the current user               |
| `ipconfig` | Show network configuration          |

## Example Usage

| Command    | Arguments               | Example                  |
|------------|-------------------------|--------------------------|
| `help`     | —                       | `help`                   |
| `cls`      | —                       | `cls`                    |
| `echo`     | `<text>`                | `echo Hello World`       |
| `date`     | —                       | `date`                   |
| `time`     | —                       | `time`                   |
| `dir`      | —                       | `dir`                    |
| `cd`       | `<folder>` / `..`       | `cd Documents`           |
| `color`    | `<BG><FG>`              | `color 0A`               |
| `start`    | `<app>.exe`             | `start notepad.exe`      |
| `animate`  | `parrot` `squirrel` `starwars` | `animate parrot` |
| `prompt`   | —                       | `prompt`                 |
| `type`     | `<filename>`            | `type readme.txt`        |
| `whoami`   | —                       | `whoami`                 |
| `ipconfig` | —                       | `ipconfig`               |

## Colors

Used with `color <BG><FG>` — first digit is background, second is foreground.

| Code | Color        | Hex       |
|------|--------------|-----------|
| `0`  | Black        | `#000000` |
| `1`  | Dark Blue    | `#000080` |
| `2`  | Dark Green   | `#008000` |
| `3`  | Dark Cyan    | `#008080` |
| `4`  | Dark Red     | `#800000` |
| `5`  | Dark Magenta | `#800080` |
| `6`  | Dark Yellow  | `#808000` |
| `7`  | Light Gray   | `#c0c0c0` |
| `8`  | Dark Gray    | `#808080` |
| `9`  | Blue         | `#0000ff` |
| `A`  | Green        | `#00ff00` |
| `B`  | Cyan         | `#00ffff` |
| `C`  | Red          | `#ff0000` |
| `D`  | Magenta      | `#ff00ff` |
| `E`  | Yellow       | `#ffff00` |
| `F`  | White        | `#ffffff` |

## Keyboard Shortcuts

| Shortcut   | Action                          |
|------------|---------------------------------|
| `Enter`    | Execute command                 |
| `↑` / `↓` | Navigate command history        |
| `Tab`      | Auto-complete file/folder names |
| `Ctrl + C` | Clear the screen                |
